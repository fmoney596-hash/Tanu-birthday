# Tanu Birthday Experience

Open `index.html` in a browser to preview the website.

## Files
- `index.html` — the complete mobile-friendly website
- `media/photo1.jpg` through `photo4.jpg`
- `media/video1.mp4` through `video3.mp4`

## Free publishing
Upload the whole folder to a GitHub repository and enable GitHub Pages:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The generated GitHub Pages address will look like:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

Keep the `media` folder beside `index.html`, otherwise the photos/videos won't load.
